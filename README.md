# 📊 Unemployment Analysis using Python

## 🧾 Project Overview

This project focuses on analyzing unemployment trends using Python.  
The main objective is to understand how unemployment rates vary across different regions and time periods, and to study the impact of Covid-19 on employment.

Unemployment is a key economic indicator, and analyzing it helps in understanding economic health, job market conditions, and policy effectiveness.

## 🎯 Objectives

- Analyze unemployment rate data
- Perform data cleaning and preprocessing
- Visualize trends using advanced graphs
- Study the impact of Covid-19 on unemployment
- Identify regional and seasonal patterns
- Generate meaningful insights for decision-making

## 📂 Dataset Information

The dataset contains the following features:

- 📅 Date – Time period of observation  
- 🌍 Region – State or region name  
- 📊 Estimated Unemployment Rate (%)  
- 👥 Estimated Employed  
- 📈 Labour Participation Rate (%)  

This data helps in analyzing both temporal and regional unemployment patterns.

## 🛠️ Technologies Used

- 🐍 Python  
- 📊 Pandas  
- 📉 NumPy  
- 📈 Matplotlib  
- 🎨 Seaborn  
- 📓 Jupyter Notebook  

## 🔧 Project Workflow

### 1️⃣ Data Collection
- Loaded dataset from CSV file

### 2️⃣ Data Cleaning
- Removed missing values  
- Converted date column into proper format  
- Renamed columns for better readability  

### 3️⃣ Exploratory Data Analysis (EDA)
- Checked distribution of unemployment rate  
- Calculated averages and summary statistics  

### 4️⃣ Data Visualization
- Histogram & KDE plot for distribution  
- Time series line chart  
- State-wise bar chart  
- Monthly trend analysis  
- Correlation heatmap  

### 5️⃣ Covid-19 Impact Analysis 🦠
- Compared unemployment rates before, during, and after Covid  
- Identified peak unemployment period  

### 6️⃣ Pattern & Trend Analysis
- Identified seasonal variations  
- Compared regional differences
